Two lines, at most 400 characters: the first explains one everyday thing to a 10-year-old through one vivid analogy; the second honestly says what the analogy maps and what it leaves out. The program writes both lines to /output/entry.txt and an AI judge compares entries two at a time.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
